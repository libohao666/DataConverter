About RegViewer

This is a web-based reimplementation of the RegViewer desktop tool (Qt/C++). The original Qt source is included in the regviewer/ directory for reference and desktop compilation.

Bug fixes vs. original:
• Bit range input is now validated (original had no validation)
• Calculator works correctly in all bit width modes (original failed in non-64bit mode, e.g. -1<<2*(2-3))
